# References

Official sources used for the project study. Accessed 2026-08-05. Product capabilities change, so the comparison should be reviewed before major releases.

## Incident response and evidence

- [CISA - Federal Government Cybersecurity Incident and Vulnerability Response Playbooks](https://www.cisa.gov/sites/default/files/2023-01/federal_government_cybersecurity_incident_and_vulnerability_response_playbooks_508c_5.pdf) - documenting indicators, correlative analysis, and sharing threat information.
- [NIST SP 800-86 - Guide to Integrating Forensic Techniques into Incident Response](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=50875) - forensic techniques, data sources, logs, and incident-response integration.
- [Splunk - Indicators of Compromise: An Introductory Guide](https://www.splunk.com/en_us/blog/learn/ioc-indicators-of-compromise.html) - accessible overview of IOC types, context, metadata, and investigation use.

## Interpretation notes

The project study distinguishes a product's **primary job** from whether a capability can be implemented through configuration, extensions, or integrations. A "relative gap" means the workflow is not the documented center of gravity for the narrow target use case; it does not mean the product is incapable.

The qualitative positioning chart is an author inference based on documented scope and deployment models. It is not a benchmark, market-share chart, or vendor ranking.
