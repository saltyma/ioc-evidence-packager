# Synthetic input fixtures

Only safe, synthetic log exports belong here. Use IANA-reserved example ranges such as `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`, and reserved `.test` domains.

Each future fixture should document its schema/source, planted matches, benign lookalikes, expected rejected records, time-zone assumptions, and the scenario it demonstrates. Never add production logs, personal data, credentials, active malware, or real victim indicators.
