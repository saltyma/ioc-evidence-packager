# Integration tests

Integration tests will run complete synthetic cases without network access and verify case persistence/migrations, background cancellation checkpoints, expected direct sightings and pivots, excluded lookalikes, all coverage states, rejected-record disclosure, source provenance, policy behavior, deterministic Case Capsule content, output hashes, and safe rendering.

Focused offscreen Qt smoke tests should prove application launch, wizard/service wiring, progress/cancel behavior, evidence detail, coverage reasons, and export validation without relying on fragile pixel-coordinate automation.
